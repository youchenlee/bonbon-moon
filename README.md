# 月亮的臉：月相與日蝕 3D 互動展示

線上版：https://youchenlee.github.io/bonbon-moon/

用 3D 模型看懂兩件事：

- **月相**：拖動時間，看月亮繞地球一圈時，從地球看到的亮面怎麼變化。附農曆日期、亮面比例和大約的月出月落時間。
- **日蝕**：看月亮的影子怎麼落在地球上。可以切換日全蝕／日環蝕、移動觀察者的緯度、讓月亮偏上偏下經過，小窗會顯示該位置看到的太陽。

地球上的影子是逐點計算「太陽被月亮遮住多少」畫出來的，所以本影、半影和日環蝕的範圍都和小窗的畫面一致。所有貼圖都由程式產生，不依賴外部圖檔。

## 開發

```sh
npm install
npm run dev      # 本機開發
npm run build    # 型別檢查 + 打包到 dist/
npm run deploy   # 打包並推到 gh-pages 分支
```

技術：TypeScript、Vite、three.js。
